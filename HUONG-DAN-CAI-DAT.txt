HƯỚNG DẪN TẢI LÊN HOSTING

1. Giải nén, tải TẤT CẢ các file và thư mục này lên cùng một thư mục trên hosting
   (thường là public_html):
     index.html, api.php, sw.js, manifest.webmanifest, thư mục icons

2. api.php dùng để lưu kết quả bài tập của các cháu trên hosting.
   - Hosting cần chạy được PHP (hầu hết hosting cPanel đều có).
   - Lần đầu có cháu nộp bài, api.php tự tạo thư mục "tanm-data" để chứa dữ liệu.
     Thư mục này được chặn truy cập trực tiếp. KHÔNG xóa thư mục này khi cập nhật trang,
     nếu xóa sẽ mất hết kết quả đã lưu.
   - Nếu báo lỗi không ghi được dữ liệu: vào File Manager, cấp quyền ghi (755) cho thư mục web.

3. Xem kết quả: Quản trị → tab "Kết quả học sinh" → nhập mật khẩu quản trị.

4. Khi sửa nội dung và bấm Xuất bản: chỉ cần tải file index.html mới lên, ghi đè file cũ.
   Các file khác và thư mục tanm-data giữ nguyên.
